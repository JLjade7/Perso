# Mon espace ✨

Mon site perso d'organisation : **Tirelire 🐷**, **Voiture 🚗**, **Notes 📝** et **Wish list 🛍️**.

- Site statique (HTML, CSS, JavaScript), sans serveur ni compte : hébergé gratuitement avec GitHub Pages.
- Les données sont enregistrées dans le navigateur de chaque appareil (localStorage).
  Réglages → « Télécharger une sauvegarde » permet d'en garder une copie ou de les copier vers un autre appareil.

## Ajouter une rubrique

1. Créer un fichier dans `js/sections/` (en copiant `notes.js` par exemple).
2. L'importer et l'ajouter à la liste dans `js/sections/index.js`.

## Tester en local

```
python3 -m http.server
```
puis ouvrir http://localhost:8000
